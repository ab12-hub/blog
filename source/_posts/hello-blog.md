# 你好，世界 👋

这个博客终于上线了。从决定搭站到真正看到页面，前后不过几个小时——但"拥有一个自己的小站"的想法，已经在心里放了很久。

## 为什么写博客

学了这么久的数学和代码，笔记散落在各处：有的在纸上，有的在聊天记录里，有的只存在脑子里——考完就忘。写博客是想给自己一个**输出的出口**：把学到的东西讲清楚，讲不清楚，就说明还没真懂。

另外，公开写下来的东西会被未来的自己看到。希望一年后回看这些文章，能清晰地看到自己走过的路。

## 这个站是怎么搭的

- **框架**：Hexo，静态博客，生成的是纯 HTML，速度快、省资源
- **主题**：Butterfly，但配色、样式、头图、头像全都换成了自己的东西，算是"深度魔改"了
- **服务器**：腾讯云轻量应用服务器（2 核 2G，北京）
- **部署**：Nginx 直接托管静态文件，简单可靠

文章用 Markdown 写，源码放在 GitHub 上。以后写新文章就是 `hexo new` + 写 + 发布，一气呵成。

## 接下来写什么

- 📐 微积分学习笔记（泰勒公式、积分技巧……）
- 🔗 数据结构笔记（链表、栈、树……）
- 🧠 深度学习实验记录（MNIST、CNN……）
- 🛠 折腾记录（服务器、博客搭建这些）

先从压箱底的学习笔记开始整理。欢迎常来看看，也欢迎交流——开张大吉 🎉
