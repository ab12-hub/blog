# 泰勒公式与拉格朗日余项

泰勒公式是微积分里"以简代繁"的终极工具：**用多项式逼近复杂函数**。带拉格朗日余项的版本，还能精确知道误差长什么样。

## 公式

设 $f(x)$ 在 $x_0$ 的某邻域内有 $n+1$ 阶导数，则：

$$f(x) = f(x_0) + f'(x_0)(x-x_0) + \frac{f''(x_0)}{2!}(x-x_0)^2 + \cdots + \frac{f^{(n)}(x_0)}{n!}(x-x_0)^n + R_n(x)$$

其中拉格朗日余项：

$$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}, \quad \xi \text{ 在 } x_0 \text{ 与 } x \text{ 之间}$$

余项的意义：误差是一个**具体的表达式**，而不是含糊的"小量"。当 $x \to x_0$ 时，$R_n(x)$ 是 $(x - x_0)^n$ 的高阶无穷小。

## 常用展开（$x_0 = 0$，麦克劳林公式）

$$\begin{aligned}
e^x &= 1 + x + \frac{x^2}{2!} + \cdots + \frac{x^n}{n!} + o(x^n) \\\\
\sin x &= x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots \\\\
\cos x &= 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots \\\\
\ln(1+x) &= x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots \quad (-1 < x \le 1) \\\\
(1+x)^\alpha &= 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \cdots
\end{aligned}$$

这五个建议背到能**默写**，考试里 90% 的泰勒题都是它们的组合。

## 怎么选 n？

看题目要什么：

- **求极限**：展开到"能把分子分母的最低次项露出来"为止。比如分母是 $x^2$，分子就展开到 $x^2$ 项。
- **近似计算**：看精度要求，余项 $|R_n|$ 要小于误差限。
- **判断正负/单调**：展开到第一个**非零项**，符号由它决定。

## 例：求极限

$$\lim_{x \to 0} \frac{e^x - 1 - x}{x^2}$$

把 $e^x$ 展开到 $x^2$：$e^x = 1 + x + \frac{x^2}{2} + o(x^2)$，代入：

$$\text{原式} = \lim_{x \to 0} \frac{\left(1 + x + \frac{x^2}{2} + o(x^2)\right) - 1 - x}{x^2} = \lim_{x \to 0} \frac{\frac{x^2}{2} + o(x^2)}{x^2} = \frac{1}{2}$$

如果只展开到 $x$ 的一次项，分子变成 $o(x)$，除以 $x^2$ 后极限不存在——这就是" n 选小了"的典型翻车。

## 一句话总结

泰勒公式 = **多项式近似 + 误差表达式**。背下五个常用展开，做题时 n 取到"刚好够用"，多一项少一项都可能翻车。
